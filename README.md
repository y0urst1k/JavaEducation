# Лабораторная работа по Java (JDK 25)

## Описание
В данной лабораторной работе необходимо разобраться с тем, как Java на самом деле хранит и обрабатывает данные:

- примитивные типы, их диапазоны и переполнение,
- особенности вещественной арифметики,
- побитовые операции и представление чисел,
- класс
String
, работа с символами и
char[]
,
- одномерные и многомерные массивы,
- перегрузка методов,
varargs
, рекурсия,
- передача аргументов в методы,
- switch
как выражение и текстовые блоки,
- ручная сборка проекта из нескольких пакетов в исполняемый JAR.
Используемая версия JDK — 25 (LTS).

Ограничения:

- Не использовать коллекции (
List
,
Map
,
Set
) и Stream API — только примитивы, строки и массивы.
- Не использовать механизм исключений (
try
,
catch
,
throw
). Некорректный ввод и особые случаи обрабатывать проверками и возвращаемыми значениями.

## Структура проекта
- `src/` — исходный код по пакетам
- `out/` — скомпилированные `.class` файлы
- `dist/` — папка с итоговым JAR-файлом
- `build.sh` / `build.bat` — скрипты сборки
- `manifest.mf` — манифест для JAR

## Требования
- JDK 25 (LTS)
- Bash (Linux/macOS) или CMD (Windows)

## Сборка и запуск

### Linux/macOS:
```bash
chmod +x build.sh
./build.sh
java -jar dist/java-labs.jar
```

### Windows
```bash
build.bat
java -jar dist/java-labs.jar
```
